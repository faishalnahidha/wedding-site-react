# Ullem — Digital Wedding Invitation

**Ullem** is a digital wedding invitation service with a modern look designed by professional UI/UX designers. Each guest gets a personal, responsive, easy-to-share invitation experience—no paper, no hassle.

Live: [mawarkumbang.ullem.com](https://mawarkumbang.ullem.com) · Service info: [ullem.com](https://ullem.com)

## About this project

This repository contains an **online wedding invitation template** plus the **Ullem Invitation Management System (IMS)**—a dashboard to manage your guest list, create per-guest invitation links, and send invitations via WhatsApp.

Stack: **Meteor 2.6** · **React 17** · **Material UI 5** · **MongoDB**

## Ullem platform features

| Feature                     | Description                                                                          |
| --------------------------- | ------------------------------------------------------------------------------------ |
| Exclusive invitations       | One invitation per guest—the guest’s name appears personally on the invitation page. |
| Simple URL links            | Links you send are short and easy to remember (`domain.com/guest-id`).               |
| Effortless WhatsApp sending | Share invitations with one click from the dashboard via WhatsApp.                    |
| Guest management dashboard  | Manage guests in a user-friendly UI (add, copy links, track RSVP).                   |

## Development

Current version: **1.2.1**.

# Ullem — Undangan Pernikahan Online

**Ullem** adalah layanan undangan pernikahan online dengan tampilan modern yang dirancang oleh UI/UX Designer profesional. Setiap undangan terasa personal, responsif, dan mudah dibagikan—tanpa kertas, tanpa ribet.

Live: [mawarkumbang.ullem.com](https://mawarkumbang.ullem.com) · Info layanan: [ullem.com](https://ullem.com)

## Tentang proyek ini

Repository ini berisi **template undangan pernikahan online** beserta **Ullem Invitation Management System (IMS)**—dashboard untuk mengelola daftar tamu, membuat link undangan per tamu, dan mengirim undangan lewat WhatsApp.

Stack: **Meteor 2.6** · **React 17** · **Material UI 5** · **MongoDB**

## Fitur platform Ullem

| Fitur                     | Deskripsi                                                                          |
| ------------------------- | ---------------------------------------------------------------------------------- |
| Undangan eksklusif        | Satu undangan untuk satu tamu—nama tamu tampil personal di halaman undangan.       |
| Link URL sederhana\*      | Link yang dikirim tidak rumit dan mudah diingat (`domain.tamu`).                   |
| Kirim undangan anti ribet | Sebar undangan dengan sekali klik via WhatsApp dari dashboard.                     |
| Dashboard kelola tamu     | Kelola daftar tamu dengan antarmuka yang user-friendly (tambah, salin link, RSVP). |

## Pengembangan

Versi saat ini: **1.2.1**.
