# Ullem — Digital Wedding Invitation

**Ullem** is a **digital wedding invitation** service with a modern look designed by **professional UI/UX designers**. Each guest gets a personal, responsive, easy-to-share invitation experience—no paper, no hassle.

> Live example: [mawarkumbang.ullem.com](https://mawarkumbang.ullem.com) · Service info: [ullem.com](https://ullem.com)

---

## About this project

This repository contains an **online wedding invitation template** plus the **Ullem Invitation Management System (IMS)**—a dashboard to manage your guest list, create per-guest invitation links, and send invitations via WhatsApp.

Stack: **Meteor 2.6** · **React 17** · **Material UI 5** · **MongoDB**

---

## Ullem platform features

| Feature                         | Description                                                                          |
| ------------------------------- | ------------------------------------------------------------------------------------ |
| **Exclusive invitations**       | One invitation per guest—the guest’s name appears personally on the invitation page. |
| **Simple URL links**            | Links you send are short and easy to remember (`domain.guest-id`).                   |
| **Effortless WhatsApp sending** | Share invitations with one click from the dashboard via WhatsApp.                    |
| **Guest management dashboard**  | Manage guests in a user-friendly UI (add, copy links, track RSVP).                   |

_As an up-to-date online wedding invitation, Ullem offers features you won’t find on conventional invitations._

### Invitation page features

- **Modern & responsive** — layout adapts to desktop, tablet, and smartphone
- **Unlimited invitations** — invite as many guests as you need
- **RSVP** — guests can confirm attendance and send messages
- **Google Maps** — maps and directions for ceremony & reception
- **Photo gallery** — moments of the couple-to-be
- **Turnkey delivery** — ready to use once content is customized

# Ullem — Undangan Pernikahan Online

**Ullem** adalah layanan **undangan pernikahan digital** dengan tampilan modern yang dirancang oleh **UI/UX Designer profesional**. Setiap tamu mendapat pengalaman undangan yang personal, responsif, dan mudah dibagikan—tanpa kertas, tanpa ribet.

> Contoh live: [mawarkumbang.ullem.com](https://mawarkumbang.ullem.com) · Info layanan: [ullem.com](https://ullem.com)

---

## Tentang proyek ini

Repository ini berisi **template undangan pernikahan online** beserta **Ullem Invitation Management System (IMS)**—dashboard untuk mengelola daftar tamu, membuat link undangan per tamu, dan mengirim undangan lewat WhatsApp.

Stack: **Meteor 2.6** · **React 17** · **Material UI 5** · **MongoDB**

---

## Fitur platform Ullem

| Fitur                         | Deskripsi                                                                          |
| ----------------------------- | ---------------------------------------------------------------------------------- |
| **Undangan eksklusif**        | Satu undangan untuk satu tamu—nama tamu tampil personal di halaman undangan.       |
| **Link URL sederhana**        | Link yang dikirim tidak rumit dan mudah diingat (`domain.tamu`).                   |
| **Kirim undangan anti ribet** | Sebar undangan dengan sekali klik via WhatsApp dari dashboard.                     |
| **Dashboard kelola tamu**     | Kelola daftar tamu dengan antarmuka yang user-friendly (tambah, salin link, RSVP). |

_Sebagai undangan pernikahan online ter-up-to-date, Ullem hadir dengan berbagai fitur yang tidak ada di undangan konvensional._

### Fitur di halaman undangan

- **Modern & responsif** — tampilan menyesuaikan desktop, tablet, dan smartphone
- **Undangan tidak terbatas** — undang sebanyak yang Anda mau
- **RSVP** — tamu dapat mengonfirmasi kehadiran dan mengirim ucapan
- **Google Maps** — denah dan petunjuk lokasi akad & resepsi
- **Galeri foto** — momen calon mempelai
- **Terima jadi** — siap pakai setelah konten disesuaikan
